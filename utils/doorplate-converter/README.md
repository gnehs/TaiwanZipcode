# 門牌資料轉換器

從政府資料開放平臺下載各縣市公開的門牌位置資料，轉成每個行政區一個 JSON，
供網站判斷門牌是否存在，並在自動完成中提示巷、弄與號。

## 使用方式

需要 Node.js 22 以上，不需要安裝套件：

```bash
node download.mjs
node build.mjs
```

`download.mjs` 依 [sources.mjs](./sources.mjs) 找出各縣市最新一期的檔案，
轉成 UTF-8 存到 `./temp`。部分縣市伺服器沒有附上完整憑證鏈，下載時會補上
[twca.pem](./twca.pem) 中的 TWCA 公開中繼憑證，憑證驗證不會關閉；嘉義縣伺服器的
DH 金鑰過短，改用 ECDHE 連線。`build.mjs` 讀取 `src/assets/zipcode.txt` 的道路清單，
以道路推回各區代碼所屬的行政區，輸出 `./result/doorplates/`。複製到
`public/doorplates/` 後即由網站使用。

每個區的檔案是「道路 → 巷弄 → 門牌號」：

```json
{ "大業路": { "": "2,10,529-3", "527巷": "15,51-1", "527巷101弄": "1,3" } }
```

`dates.json` 記錄各縣市資料的日期：縣市在資料名稱或檔名中寫明的民國日期
（`kind: "data"`），沒寫時改用檔案最後上傳的日期（`kind: "updated"`）。網址中的
西元日期是上傳系統的戳記，檔案替換後仍會沿用，因此不採用。

樓層合併為同一個門牌；臨時門牌、特殊門牌、附號與建物名稱門牌不收錄。道路
不在郵局資料中的列也會略過。任一縣市可用的列低於 85% 時，轉換會直接失敗，
避免官方格式改變時靜默產出殘缺資料。

## 涵蓋範圍

臺北市、新北市、桃園市、臺中市、臺南市、高雄市、基隆市、新竹市、新竹縣、苗栗縣、
彰化縣、雲林縣、嘉義縣、屏東縣、臺東縣、花蓮縣、澎湖縣、金門縣。

雲林縣的伺服器拒絕自動下載，資料由人工下載後以 `manual.mjs` 轉成只含必要欄位的
`manual/雲林縣.csv` 並提交，Action 不會自動更新。要更新時，從政府資料開放平臺
下載該縣的 JSON 檔，再執行：

```bash
node manual.mjs 雲林縣 a.json b.json c.json
```

基隆市的資料放在市府網站的民政處頁面，轉換器從頁面上的 CSV 連結下載。

臺中市的資料不在政府資料開放平臺，而是臺中市資料開放平臺上一份列出每月
Google Drive 檔案的索引；轉換器讀取索引後下載最新一個月。該資料集標題含年份
（115 年），跨年後若改以新資料集發布，需要更新 `sources.mjs` 的索引網址。

其他縣市目前沒有公開門牌資料。沒有資料的地區，網站維持原本的查詢行為。

## 自動更新 Action

`.github/workflows/updateDoorplates.yaml` 每月 1 日執行，也支援手動觸發；
門牌檔有差異時才提交 `chore(data): update doorplates`。
